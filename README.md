# skydxx.xyz — личный сайт

Исходники статического сайта [skydxx.xyz](https://skydxx.xyz). Страница написана на HTML, CSS и JavaScript без фреймворка.

`index.html`, `favicon.svg` и папку `photos/` можно разместить на обычном статическом хостинге. Галерея использует явный список опубликованных снимков в `index.html`; для добавления фотографии добавьте файл в `photos/` и его имя в массив `pics`.

Фотографии в репозитории опубликованы в JPEG без EXIF и исходных RAW-файлов.
